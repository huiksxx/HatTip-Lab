# Live2D model-pack template

Place `pet-model.json` next to your `.model3.json` or `.model.json`. You may
start from `pet-model.example.json`, rename it, and fill in truthful licensing
information.

The app never treats this declaration as proof of rights. The importing user is
responsible for complying with the model author's terms.

Model packs are data-only. JavaScript, Python, executables, HTML, and other
active content are ignored during import.
